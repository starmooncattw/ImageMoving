# GIF 編輯器需求文件

## 專案概述
- 純 HTML + JavaScript 本地 GIF 編輯器
- 無需網路，離線可用
- 單一 HTML 檔案
- 目標大小：≤300 KB

## 技術方案
- **方案 A**：使用現成庫（gifuct-js + gif.js）
- 所有庫代碼內嵌至 HTML
- 預估大小：150-200 KB

## 核心功能

### 1. 基礎操作
- 載入單個/多個 GIF 檔案
- 預覽播放/暫停控制
- 下載編輯後的 GIF

### 2. 幀編輯
- 顯示所有幀縮圖
- 刪除指定幀
- 拖拽調整幀順序
- 反轉播放順序

### 3. 速度調整
- 整體播放速度調整
- 單幀延遲時間設定

### 4. 圖片處理
- 縮放/調整尺寸
- 旋轉（90°/180°/270°）
- 水平/垂直翻轉
- 裁剪功能

### 5. 濾鏡效果
- 亮度、對比度、飽和度調整
- 基本濾鏡（黑白、復古等）

### 6. GIF 合併 ⭐
- **時間軸合併**：GIF A 播完接 GIF B
- 處理不同尺寸的 GIF
- 處理不同幀率的 GIF
- 可調整合併順序

### 7. 透明背景處理 ⭐
- 完整保留原始透明度
- 棋盤格預覽（可切換背景）
- 顏色轉透明工具（含容差調整）
- 透明轉顏色填充
- 合併時透明度處理選項
- 濾鏡使用提醒（標註透明安全性）
- 透明度檢測與統計

## 界面要求
- 繁體中文介面
- 直覺易用的操作流程
- 即時預覽效果
- 響應式設計（支援各種螢幕）

## 技術限制說明
- GIF 僅支援完全透明/不透明（無半透明）
- 處理大型 GIF 可能有效能限制
- 部分濾鏡可能影響透明度

## 優先級
1. P0（必須）：基礎操作、幀編輯、透明保留
2. P1（重要）：合併功能、速度調整、預覽
3. P2（加分）：進階濾鏡、透明工具、優化功能
